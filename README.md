# 桌面双环 · 测试版 3

独立 iOS 16.x Rootless 越狱插件 `com.axs.twindial`。保持 test2 的分行颜色、天气字段、播放按键与素材不变。

- **左圈上弧**只显示歌词，下弧只显示曲名和歌手。两个左弧设有互不重叠的绘制区域，长文字截尾。系统当前播放信息没有已验证的通用歌词字段，不抓取音乐 App 的歌词。用「导入 LRC 歌词」选一份 UTF‑8 时间轴文件，文件名须为 `歌手 - 曲名.lrc`，和系统上报的歌手及曲名一致（空格、括号也要一致）。本测试版只保存一份，新导入会替换上一份；匹配后依赖播放器上报的进度更新，桌面轮询约两秒一次。无匹配只显示提示或手动开启的示例，不在下弧补歌词。
- **自动定位**：设置 → 隐私与安全性 → 定位服务，打开总开关；再到桌面双环开启「天气跟随当前位置」（默认开）。回桌面首页等待。插件有「自动定位帮助」。没有已验证可从系统设置单独授权 SpringBoard 的入口；若仍提示「桌面定位未获授权」，打开定位总开关或授权天气 App 都不能保证给该宿主授权。不自动发起权限申请、不绕过权限；暂时可关闭跟随并手填城市。自动定位权限和实际更新未做真机验证。
- **顶部停靠**：和旧版使用不同设置键，旧版位置不会把双环拖回屏幕中部。默认在首页图标页可用区域顶部居中；横纵仅可在 −12～+12 点内微调，支持输入两位小数。仍是浮层，**不让原生图标自动下移**，请用顶部有空位的首页验收。

## 构建

用完整源码（含隐藏的 `.github`）覆盖原仓库并提交新 commit。Actions → Build TwinDial → `packages-rootless` 取包。此次为源码更新，未跑 GitHub Actions，未产出新的 deb 或真机验证。
