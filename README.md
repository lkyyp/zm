# 桌面双环 · test4 数据接入测试

独立 iOS 16.x Rootless Theos 源码；包名 `com.axs.twindial`。在 test3 上独立实现 Solo 1.0.1 静态分析确认的数据路径，不需要安装 Solo，也不读取它的配置或数据。

## 如何测试

1. 将完整工程（含 `.github`）覆盖到原仓库并提交新 commit；Actions → Build TwinDial → `packages-rootless`。此处没有现成 deb。
2. 在插件内打开「自动匹配在线歌词」（默认关闭；开启会向 LRCLIB 发送当前曲名、歌手、专辑、时长，不发送账号）。用网易云 9.6.25 播歌再回首页，比较网易云的歌词与上弧；切歌、暂停续播和拖动进度后再比较。无需手动导入，已删除导入和示例入口。只接受返回曲名、歌手、专辑一致且时长偏差不超过 1 秒的同步歌词，缺字段或无匹配不猜；可能漏匹配，不能用作全曲库承诺。下弧仍是曲名和歌手。
3. 「天气跟随当前位置」保持开启，系统天气的「始终」不用再改。读取 `WeatherPreferences.localWeatherCity`，要求对象明确标注当前地点、且有一小时内的更新时间。回到首页以及首页持续显示时每分钟检查一次，不主动刷新或请求位置，不把系统定位发给第三方，也不读取电话助手数据。若暂时读不到就提示「系统当地天气未就绪」。本版系统天气先显示地名、天气状态及当前温度（字段可读时），高低温、降水、预警还没接通。手动模式的旧 Open-Meteo 路径独立保留。

**仍未实现图标和 Colorful Widget 让位。** 本版只是两条数据链的测试源码，顶部有小组件的首页上可能挡住它；不建议当成日用版，勿把布局检查当成原生让位。原配色、顶部位置、按键未改。没有运行 GitHub Actions、没有装机；尤其系统天气缓存能否更新以及网易云是否上报足够元数据须真机验证。
