# 桌面双环 · 原生测试版 1

独立 iOS 16.x 越狱插件 `com.axs.twindial`，默认构建 Rootless，仅注入 SpringBoard。不依赖 Solo，不更改旧音乐插件。

## 构建与启用

解压源码，将工程根目录的内容（含隐藏的 `.github`）上传到自己的仓库，手动运行 Actions 的 **Build TwinDial**，取 `packages-rootless` 的 deb；或在具备 Apple clang、Theos 和 iOS 16.5 SDK 的机器上运行 `sh build.sh rootless`。工程构建目标为 arm64 + arm64e；通用 Linux 编译器可能生成不了 iOS 16 兼容的 arm64e，不应拿这种结果装机。安装后在「设置 → 桌面双环」开启总开关。

## 首轮测试

1. 开启「显示两行示例歌词」，回桌面看上下弧是否顺着圆边，中间保留三个按键。真实同步歌词尚未接入，关掉示例不会冒充正在播放的歌词。
2. 先在音乐 App 播一首歌再回桌面。按左、中、右分别试上一首、播放／暂停、下一首；然后在左圈上下滑，试扬声器和耳机的媒体音量。右图来自上传素材，左图为原图水平镜像。按钮只向系统当前媒体会话发命令，不冷启动 App。
3. 调「整体横向／整体纵向」，双环和连接桥一起移动；左右圆大小可分别调，边缘有防裁切限幅。这个浮层不重排图标，可优先放在有空位的桌面页。选背景、设每圈秒数（0 停止）、改字色后回桌面查看。系统减少动态效果开启时不旋转。
4. 填天气城市名或坐标；上弧是当前天气＋当地当天最低/最高温；下弧是地名＋当天最高降水概率；中间保留「平安·喜乐」。天气来自 Open-Meteo，不请求定位。未接入真实预警，不会显示「无预警」。
5. 回到 App、锁屏或切换器确认双环不挡界面。异常时在设置关闭总开关；若打不开设置，在包管理器卸载后注销。
