# 桌面双环 · 测试版 2

独立 iOS 16.x 越狱插件 `com.axs.twindial`。沿用测试版 1 修正后的 Rootless 工作流、按键素材和原来的系统播放控制。不覆盖旧的源码包。

## 构建

把完整工程（包括隐藏的 `.github`）覆盖到原仓库，提交新 commit。Actions 的 **Build TwinDial** 成功后，从 `packages-rootless` 下载 deb。此处交付源码，未运行 CI 或安装真机。

## 本版怎么测

1. 默认「仅在桌面首页显示」，翻到第二页后应消失，回首页恢复。关闭此选项可恢复旧版跟随根图标页的行为。继续检查锁屏及进入 App 时不显示。
2. 横纵滑条显示两位小数的百分比；要更细就用「精确输入整体位置」。纵向百分比映射到可移动区间，避免在两端拖一截却不动；默认与旧版实际位置可能略有差别。位置和尺寸调整在返回桌面后查看。
3. 「分行设置文字颜色」可分别设置左上、左下、右上、右中、右下和补充信息的色号，留空继承全局旧色。先在音乐 App 播放，回桌面验证左下弧随切歌显示系统报出的曲名、歌手；长文字会截断。左上仍未接入同步歌词，示例开关只影响左上。
4. 「天气跟随当前位置」默认开启，仅挂件显示且系统已允许当前桌面宿主定位时使用系统位置；未授权不会绕过或伪造授权。约千米级定位，坐标四舍五入到小数两位，使用 Apple 地理编码取地名、Open-Meteo 查询天气，不持久化自动坐标。离开桌面时停止监听，重新显示时重新取定位；可关闭并退回手填。真机上如出现「桌面定位未授权」，这是宿主权限未满足，保留手填作暂用，不算自动定位已验收。官方天气预警未接入。

**尚未实现图标让位。** 此包仍是浮层，可覆盖原生图标，请只把它放到空位。这版没有修改图标网格、容量、页面归属或拖放；不能把空位摆放当成自动让位。真正的原生让位宜先试首页顶部或底部留出一整条，保留原有行列及顺序，并实测满页和带小组件的首页，不能只移动图标视图。
